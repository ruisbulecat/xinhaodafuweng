# 信奥大富翁 · 局域网联机说明

## 一、启动服务器

在 Windows 下双击 **`start-lan.bat`**。

启动器会优先使用 Node.js；如果电脑上没有安装 Node.js，会自动改用 Windows 自带的 PowerShell 服务器，**不需要安装任何东西**。

启动后会自动打开浏览器，并显示类似：

```
本机地址:  http://127.0.0.1:8765
局域网:    http://192.168.1.23:8765
```

## 二、多台设备加入

1. 确保所有电脑 / 手机连接**同一个 Wi-Fi 或同一个局域网**。
2. 在房主电脑上打开大厅右下角的 **「局域网联机」**。
3. 房主点「创建房间」，把 4 位房间号告诉其他人。
4. 其他人在自己设备的浏览器打开上面那个 `http://192.168.x.x:8765` 地址，点「加入房间」并输入房间号。
5. 房主选择 **棋盘尺寸（40 / 72 / 96 格）**、难度、回合数，然后点「开始比赛」。

> 如果其他设备打不开页面，请检查 Windows 防火墙，允许 Node.js / PowerShell 的“专用网络”访问。
> 服务器端口默认是 `8765`，可以用 `start-lan.bat 9000` 改成 9000。

## 三、联机规则

- 房主浏览器是唯一权威：所有骰子、租金、事件和 AI 都在房主电脑上结算。
- 其他玩家收到的是状态快照，只能在自己的回合执行操作。
- 掉线不会立刻踢出房间，重新打开页面加入即可；同一房间最多 4 人。
- 房主退出时房间会关闭。

## 四、服务器说明

| 文件 | 说明 |
| --- | --- |
| `server.js` | 零依赖 Node.js 服务器（推荐，任何装了 Node 的电脑都能用） |
| `server.ps1` | 零依赖 Windows PowerShell 服务器（没装 Node 时自动使用） |
| `start-lan.bat` | 一键启动器 |

也可以手动启动：

```bat
node server.js
```

或

```bat
powershell -NoProfile -ExecutionPolicy Bypass -File server.ps1
```

游戏本身仍然是纯前端，直接双击 `index.html` 也能单人游玩；局域网功能需要先启动服务器。
